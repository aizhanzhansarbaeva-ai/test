# 2. Департамент приема документов (START)

**Сотрудники:** DBA — Дария; EMBA — Гүлсезім

**Зона ответственности:** прием документов, оформление договоров, формирование личных дел,
подготовка электронной папки группы и передача документов в Офис студентов и
Академический департамент.

---

## 2.1. Прием документов

- Проверять корректность данных в приказе о зачислении — Ф.И.О. должны **полностью**
  соответствовать документам.
- Подготавливать договоры на обучение.
- Подготавливать трехсторонние договоры (при необходимости).
- Проверять основания для предоставления скидок и собирать подтверждающие документы.
- Формировать личные дела обучающихся.
- Контролировать наличие оригиналов документов.
- Утверждать академический календарь (подпись, печать, дата, номер редакции), сканировать
  и загружать в папку группы. При изменении календаря после утверждения номер редакции
  повышается, новый скан заменяет прежний, прежняя редакция переносится в подпапку «Архив» —
  см. [Регламент календаря и расписания](07-scheduling.md), п. 7.9.

## 2.2. Подготовка документов группы

> До начала обучения создать **электронную папку группы**.

### 2.2.1. Договоры

- Проверить наличие всех подписей и QR-кодов.
- Загрузить договоры в установленном порядке.
- При наличии трехстороннего договора загрузить его скан-копию.
- Количество договоров должно соответствовать количеству обучающихся в приказе.

### 2.2.2. Фотографии

- Собрать фотографии 3×4 всех слушателей для оформления Face ID и пропусков.

### 2.2.3. Учебные документы

Загрузить в папку группы:

- академический календарь (PDF);
- расписание занятий;
- график работы преподавателей;
- график оплаты обучения;
- график оплаты траншей.

## 2.3. Передача документов

1. Передать полный комплект документов в Офис студентов.
2. Подписать акт приема-передачи документов.
3. Сохранить акт в общей папке.
4. Заполнить данные обучающихся в системе **Univer**.
5. Передать информацию в бухгалтерию (при необходимости).
6. До начала ориентационной недели передать электронный пакет документов
   в [Академический департамент](04-academic-process.md).

## 2.4. Подготовка документов иностранных обучающихся

- Контролировать оформление виз.
- Контролировать сроки действия виз.
- Организовать нострификацию дипломов.
- Проверять наличие апостиля.
- Содействовать получению ИИН.
- Организовать нотариальное заверение документов.

## 2.5. Организация приема

- Разработать чек-лист приема документов.
- Подготовить порядок проведения собеседования.
- Утвердить состав приемной комиссии.
- Подготовить гайд для поступающих.

---

## Чек-лист готовности группы к началу обучения

- [ ] Данные в приказе о зачислении сверены с документами
- [ ] Договоры на обучение подготовлены и подписаны
- [ ] Трехсторонние договоры оформлены (при необходимости)
- [ ] Основания для скидок проверены, подтверждающие документы собраны
- [ ] Личные дела обучающихся сформированы
- [ ] Оригиналы документов в наличии
- [ ] Академический календарь утвержден, отсканирован и загружен
- [ ] Создана электронная папка группы
- [ ] Договоры: подписи и QR-коды проверены, файлы загружены
- [ ] Количество договоров = количеству обучающихся в приказе
- [ ] Фотографии 3×4 собраны (Face ID и пропуска)
- [ ] Загружены: расписание, график работы ППС, график оплаты обучения, график траншей
- [ ] Комплект передан в Офис студентов, акт подписан и сохранен
- [ ] Данные внесены в систему Univer
- [ ] Информация передана в бухгалтерию (при необходимости)
- [ ] Электронный пакет передан в Академический департамент до ориентационной недели
