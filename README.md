# FIBS — Регламенты и бизнес-процессы департаментов

Репозиторий содержит описание бизнес-процессов и зон ответственности департаментов
**Farabi International Business School (FIBS)** по программам **MBA, EMBA и DBA**.

## Логика процесса

Жизненный цикл обучающегося проходит через три ключевых этапа:

```
Маркетинг  →  START  →  PROCESS  →  FINISH
(привлечение) (прием)  (обучение)  (выпуск)
```

| Привлечение | [Департамент маркетинга](docs/01-marketing.md) | Темірлан, Исажан, Бегалы, Дәулет |

## Точки передачи ответственности

Границы между департаментами — это места, где чаще всего теряются документы и сроки.
Ниже зафиксированы обязательные передачи:

1. **Маркетинг → Департамент приема документов**
   После выхода приказа о зачислении и подтверждения прибытия обучающегося маркетинг
   передает информацию о прибытии в Департамент приема документов.

2. **Департамент приема документов → Офис студентов**
   Передача полного комплекта документов с подписанием акта приема-передачи;
   акт сохраняется в общей папке.

3. **Департамент приема документов → Академический департамент**
   До начала ориентационной недели передается электронный пакет документов группы.

4. **Академический департамент → Департамент выпуска**
   Передача обучающихся, выполнивших академические требования, на итоговую аттестацию.

5. **Департамент выпуска → Архив**
   Передача личных дел выпускников после выдачи дипломов.

## Ведение документа

- Изменения вносятся через pull request.
- Каждый раздел ведет соответствующий департамент.
- Пункты, требующие уточнения, помечаются как `> **Требует уточнения:**`.
